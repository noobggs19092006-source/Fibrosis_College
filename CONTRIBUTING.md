# Contributing

Thanks for contributing to the ASK1 prediction pipeline.

## Development workflow

1. Create a feature branch from `main`.
2. Create and activate a Python virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Make focused changes and update documentation when behavior changes.
5. Run the smallest relevant validation before opening a pull request.
6. Describe data, model, and reproducibility impacts in the pull request.

## Data and generated artifacts

Do not commit credentials, private or regulated data, local environments, cache directories, or unreviewed generated outputs. When changing datasets or trained artifacts, document their source, generation command, and any licensing or attribution requirements.

## Pull requests

Pull requests should explain what changed, why it changed, and how it was validated. Keep unrelated refactors out of feature changes.
